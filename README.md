# Tt odone

A simple and clean **To-Do Web App** built using **React**.  
It helps you add, edit, complete, and delete daily tasks easily.

---

## ✨ Features
- Add new tasks  
- Edit existing tasks  
- Delete tasks  
- Mark tasks as completed / not completed  
- Filter tasks: **All / Active / Completed**  
- Saves tasks automatically using **LocalStorage**  
- Responsive and mobile-friendly UI

---

## 🛠 Tech Stack
- **React (JavaScript)**
- **HTML5 & CSS3**
- **LocalStorage** for data persistence

---

## 🚀 Installation & Run
```bash
git clone <your-repo-url>
cd todone
npm install
npm run dev
```
